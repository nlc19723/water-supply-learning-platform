# 供水学习平台（Water Supply Learning Platform）

面向供水公司全员的材料学习与作业支持平台。纯静态单页应用（SPA），无需后端，可直接部署到任意静态托管服务；同时支持 PWA（可添加到主屏幕、离线访问）。

## 功能

- **材料库**：按「一级分类 → 二级分类」浏览管材、管件、阀门、仪表、井盖等材料，支持关键词搜索、规格解析、术语高亮；每张材料卡片可展开实物大图与安装图。
- **课程体系**：多板块课程，支持分步骤学习、进度本机保存、深链（`#courses/<课程>/<步骤>`）。
- **考核练习**：题库自测、即时判分、错题回顾。
- **知识问答**：示例知识库问答与常见问题。
- **统计**：学习进度与答题情况统计。

## 技术特点

- 零依赖、零构建：原生 HTML / CSS / JavaScript，数据以 JS 数组形式内置（`static/materials.*.js`、`static/curriculum.*.js`）。
- **PWA**：`manifest.json` + `sw.js`，支持安装到桌面；采用双缓存分层策略：
  - `APP_CACHE`（版本号命名）：页面 / 脚本 / 数据，发版即更新。
  - `ASSETS_CACHE`（图标内容指纹命名）：图标与图片，内容不变则跨版本复用，发版后图片零重复下载。
- 图片资源文件名带内容哈希，内容变更即 URL 变更，缓存自动失效。
- 版本自愈：页面每 60 秒检查 `version.json`，发现新版本自动刷新。

## 本地运行

用任意静态文件服务器启动仓库根目录即可，例如：

```bash
python3 -m http.server 8080
```

浏览器打开 <http://localhost:8080>。

> 直接双击 `index.html`（`file://` 协议）可浏览主体内容，但 Service Worker 与部分特性需要 HTTP(S) 环境才能生效。

## 目录结构

```
.
├── index.html            # 应用入口与页面结构
├── manifest.json         # PWA 应用清单
├── sw.js                 # Service Worker（双缓存分层）
├── version.json          # 版本号标记（供版本自愈检测）
├── release.sh            # 带版本戳的一键发布脚本（需按实际环境配置）
├── favicon.png / icons/  # CSD 蓝色六边形 logo（favicon 与 PWA 图标）
├── images/               # 材料实物图与安装图（文件名含内容哈希）
└── static/               # 应用脚本、样式与数据（文件名含内容哈希）
```

## 发布

`release.sh` 演示了发布流程：递增版本号、精确同步 5 处版本锚点、注入图标资产指纹到 Service Worker、校验后发布。脚本中的发布命令与锁路径需按实际部署环境调整。
